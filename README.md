# ✈️ USA Flight Delay Prediction  

## Overview  
Flight delays pose significant challenges for both passengers and airlines, often resulting from a mix of operational and environmental factors.  
This project leverages **data-driven methods** to predict the **occurrence of flight delays** for domestic flights within Washington State.  
By combining **flight operation records** with **hourly weather data**, the study explores key determinants of delay and develops **machine learning models** capable of anticipating delayed flights with improved accuracy.


## 🗂 Data Source  
- **Flight operation data** were obtained from the [U.S. Bureau of Transportation Statistics (BTS)](https://www.transtats.bts.gov/Fields.asp?gnoyr_VQ=FGJ).  
- **Weather data** were retrieved from the [NOAA Global Hourly Dataset (NCEI)](https://www.ncei.noaa.gov/access/search/data-search/global-hourly).

## 🎯 Objectives  
- Analyze historical flight and weather patterns.  
- Identify major determinants of departure and arrival delays.  
- Develop predictive models (e.g., Random Forest, XGBoost, LightGBM).  
- Build a prototype application for real-time delay prediction.  

## 🧰 Tech Stack  
- **Languages:** Python (Pandas, NumPy, Scikit-learn).
- **Visualization:** Matplotlib, Seaborn, Plotly.  
- **Deployment:** Streamlit.
